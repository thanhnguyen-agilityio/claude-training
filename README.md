# claude-training

Claude training plan (https://dojo.agilityio.dev/) — Dev track, 15 days. Goal: finish fast, keep notes short.

| File | Purpose |
|---|---|
| [PLAN.md](PLAN.md) | Course plan condensed (days, checkpoints, courses) |
| [TODO.md](TODO.md) | Daily checklist + progress tracker |
| [notes/](notes/) | `day-NN.md` learnings; `ideas.md` backlog |
| [ai-kit/](ai-kit/) | Reusable Claude Code kit (CLAUDE.md, commands, skills, settings) — copy into any project |
| [sample-project/](sample-project/) | Practice repo (LangGraph agent + FastAPI + Streamlit) |

## Workflow
1. Open `TODO.md`, work today's day.
2. Log in `notes/day-NN.md`: **Learned** (≤5 bullets) · **Prompts that worked** · **Gotchas** · **Kit candidates**.
3. Idea for later → one line in `notes/ideas.md`.
4. Anything reusable → `ai-kit/`.
5. Tell Claude "update todo" to tick items.

Rules: sandbox only, no client data in AI tools. AI output = proposal until run.
