## The course in one page

Claude is an AI thinking partner, not only a chatbot. You bring context and judgment; Claude
brings the intelligence. The course moves from talking to Claude, to organizing knowledge, to
connecting tools, to using Claude in other apps.

| Surface / feature | What it is | Use it when | Lesson |
| --- | --- | --- | --- |
| Chat (Claude.ai, desktop, mobile) | Turn-by-turn conversation; uploads, web search, models, Thinking, Memory | Brainstorm, draft, ask, explain, quick tasks | 1–3 |
| Desktop app: Cowork | Hand off a whole task; folder access, scheduled tasks, subagents, plugins | Multi-step work, finished files, work across tools, on a schedule | 4 |
| Desktop app: Code tab | Claude in a codebase (local or cloud) | Developers writing and testing code | 4, 12 |
| Projects | Workspace with knowledge, instructions, sharing | Ongoing work, repeated reference material, team use | 5 |
| Artifacts (Design, Slides, Docs, other) | Standalone outputs saved in the Artifacts tab; edit, comment, share, export | Decks, docs, prototypes, dashboards, interactive tools to keep and share | 6 |
| Skills | Reusable instructions Claude loads for a task (built-in file creation, custom) | Repeatable workflows with the same steps every time | 7 |
| Connectors (MCP) | Link Claude to cloud tools (web) or local tools (desktop extensions) | Work with your real email, files, tickets, chats | 8 |
| Enterprise search | "Ask {Org}" project over company sources (Team/Enterprise) | Find and combine internal knowledge, with citations | 9 |
| Research | Multi-step, multi-source investigation with citations (paid plans) | Reports, comparisons, market and vendor analysis | 10 |
| Claude Code, Tag, Design, Microsoft 365, Chrome | Claude inside other tools | Code, Slack, UI prototypes, Excel/PowerPoint/Word/Outlook, browser | 11–12 |

Simple rules to remember:
- **Prompt = stage + task + rules** (context, action, style/format). Then iterate.
- **Projects store knowledge; skills define process.** They work together.
- **Artifacts** for things you keep and share; **file creation** for files to download.
- **Quick fact** = web search; **hard reasoning** = Thinking; **many sources** = Research;
  **company knowledge** = Enterprise search.
- **Connectors** only give Claude somewhere to look; Claude sees only what you can see.
- **Test before you trust**: run Claude on work you already know (a simple eval), and stay
  accountable for the result (4D: Delegation, Description, Discernment, Diligence).
