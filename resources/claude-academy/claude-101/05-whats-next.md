# Lesson 13: What's next?

Short recap lesson (2 min) plus the course quiz and badge.

## Recap of the course

| Section | Main points |
| --- | --- |
| Getting started | Claude is a helpful, harmless, honest thinking partner; use web, desktop, mobile (synced); prompt = set the stage, define the task, specify rules |
| Better results | Iterate; fix generic or off-tone answers with specific context; 4D = Delegation, Description, Discernment, Diligence |
| Organizing work | Projects = persistent knowledge, instructions, sharing; artifacts = outputs saved in the Artifacts tab; skills = instruction packages for specialized workflows |
| Expanding reach | Connectors link your tools; Enterprise search = one project for company knowledge; Research = multi-source investigation |
| Putting it together | Claude fits many roles; also Claude Code, Claude Tag, Claude for Microsoft 365, Claude in Chrome |

## Where to learn more

- Free courses: AI Fluency (collaborating with AI), AI Capabilities and Limitations,
  Claude Code in Action, Introduction to Claude Cowork
- Use Case Gallery, Anthropic Help Center, prompting documentation, Connector Directory

## Advice from the course

- Start simple: pick one recurring task this week (an email, meeting notes, a spreadsheet),
  try it with Claude, iterate, learn what works.
- Claude is a collaborator, not a replacement. Bring your expertise, context and judgment.
