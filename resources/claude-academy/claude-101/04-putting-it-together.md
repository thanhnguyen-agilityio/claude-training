## Lesson 12 — Other ways to work with Claude

**Core idea:** Claude is the intelligence; Claude.ai is one place to use it. Other tools meet you
where you work.

| Tool | Use it when | Runs in |
| --- | --- | --- |
| Claude Code | Build features, debug, explore an unfamiliar codebase, automate chores (lint, merge conflicts, release notes) | Terminal, IDE, browser, Slack |
| Claude Tag | Draft replies, summarize threads, prep for meetings, onboard to a team, hand a bug report to a Claude Code session | Slack |
| Claude Design | Brief/sketch/screenshot to UI prototype; compare variations; use your design system; hand off to Claude Code | Any conversation, Artifacts tab, claude.ai/design |
| Claude for Excel | Understand multi-tab workbooks, update assumptions, trace #REF!/circular errors, build pivots and charts | Excel sidebar |
| Claude for PowerPoint | Outline to first draft, tighten copy, restructure, keep template/brand formatting | PowerPoint sidebar |
| Claude for Word | Draft in your template, revise sections, work through tracked changes and comments, ground claims in sources | Word sidebar |
| Claude for Outlook (beta, installed separately) | Triage mail, draft replies with thread and calendar context, summarize chains | Outlook sidebar |
| Claude in Chrome | Summarize pages, draft email, fill repeated forms, test sites, work across tabs and internal tools | Chrome sidebar |

**Claude in Chrome notes:** paid plans only (not Free). On Team/Enterprise, admins can turn it
off and limit sites. Use it for low-risk tasks on trusted sites; it asks before high-risk actions
(buying, sharing personal data); financial and adult sites are blocked by default.

**Claude Design availability:** in conversations on every plan (Team admin can turn off; Enterprise
via Organization settings > Artifacts); the standalone claude.ai/design space has its own settings.
