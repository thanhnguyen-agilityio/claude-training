# Lessons 8–9: Description

## Lesson 8 — A closer look at Description (4 min video)

Description is more than writing a prompt. It means setting up a working relationship in which
you and the AI can collaborate well. The AI can't read your mind.

| Part | You define… | Examples |
| --- | --- | --- |
| Product | *what* to create | output, format, audience, style |
| Process | *how* the AI should approach it | steps, method, what to consider first |
| Performance | *how the AI should behave* while working with you | concise vs. detailed, challenging vs. supportive |

- Treat the AI as an interactive partner, not a database or a vending machine.
- Being clear up front saves rounds of rework.

**Exercise — Bad Prompt Makeover.** Ask Claude for a few weak prompts. Rewrite each one with
product, process and performance details, then ask Claude what the rewrite improves. After
about 5 minutes, swap roles: give Claude weak prompts and see what it adds and how it
structures them.

## Lesson 9 — Effective prompting techniques (Deep Dive 2)

Prompt engineering means designing good instructions for an AI. It's normal communication
skill plus a few AI-specific habits.

Six basic techniques:

1. **Give context**: what you want, why, and the relevant background
2. **Show examples** of the output style or format you want
3. **Set constraints**: format, length and other requirements
4. **Split complex tasks into steps**
5. **Ask the AI to think first** before it answers
6. **Set a role or tone** for how it should communicate

- **Secret weapon:** ask the AI to help improve your prompt.
- Prompting is **iterative** and can be done together with the AI. Expect to refine.
- Prompts that work usually include a clear task overview, a format spec, explicit
  constraints and background.

**Reflect:** Which technique would help your daily AI use most? Redo the Bad Prompt Makeover
using these techniques.
