## The framework in one page

**AI Fluency** = working with AI in ways that are **effective, efficient, ethical and safe**.

Three ways to engage with AI:

| Mode | What it means |
| --- | --- |
| Automation | AI does a specific task you defined |
| Augmentation | You and AI think and work together as partners |
| Agency | You set up the AI's knowledge and behavior so it works on its own for you |

Four competencies (the **4Ds**), each with three parts:

| Competency | Question it answers | Parts |
| --- | --- | --- |
| Delegation | What should AI do, what should I do? | Problem, Platform, Task awareness |
| Description | How do I tell AI what I need? | Product, Process, Performance |
| Discernment | Is what I got good enough? | Product, Process, Performance |
| Diligence | Am I using AI responsibly? | Creation, Transparency, Deployment |

Description and Discernment form a loop: describe → evaluate → refine → repeat.
