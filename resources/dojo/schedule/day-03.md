# Day 03 — Fix, review, merge — Checkpoint 1

Everyone · Checkpoint

- **Workshop:** fix the Day-2 bug on a branch, small commits, test included.

**Exercise**

Write the PR description (what/why/how tested/screenshots) — draft with Claude, edit by hand; open the PR against the training repo.

- **Peer swap:** everyone reads one other PR and comments "could I implement/review from this description alone?"
- **Workshop:** code-review checklist walkthrough (correctness → tests → readability → security basics → scope). Review your partner's PR with ≥3 actionable comments.

**Exercise**

Resolve a seeded conflict on your PR and merge it; delete the branch.

- **Course (BA/QA path):** start [Real-World AI for Everyone](../courses.md) on Coursera.

### Checkpoint 1 — Pass to continue

1. Reproduce an assigned bug and write the repro in the ticket.
2. Fix on a branch with a test (BA/QA: spec the fix and co-sign a dev's).
3. PR with a self-contained description.
4. One peer review with 3 actionable comments; one merge with conflict resolved.

**Lead:** anyone who fails repeats the failed exercise as paired homework during Days 4–5 — there is no standing slack week; the pace assumes the fundamentals held.

## Skills today

### review-checklist skill
The Day-3 checklist becomes enforced practice.

*How to set up:* Nothing to install beforehand — the team turns this into an installable skill during Day 7+; today you follow the Day-3 checklist by hand.
