# Day 15 — Review, merge, demo — Final checkpoint

Everyone · Checkpoint

**Morning — review and merge:**

- Cross-review: dev reviews QA's test code; QA reviews a dev PR; BA checks merged behavior against the acceptance criteria — gaps become same-day tickets.
- Merge, tag a release, run the deploy; Remote-Control/Dispatch demo: approve and steer a session from a phone.

**Afternoon — demo, retro, playbook:**

- Each pair demos 10 minutes — the flow, not slides: ticket → plan → PR → review → tests → artifact → shipped.
- **Retro:** what to standardize (`CLAUDE.md` rules, skills, hooks, review checklist) — capture as repo issues owned by named people.

**Exercise**

**Personal playbook:** each person writes their one-page "how I work with Claude" — favorite workflows, prompts, guardrails — shared as artifacts.

### Final checkpoint — Company-ready

- Capstone shipped end-to-end.
- Every person has demonstrated their track's skill bar (Days 3/6/11 checklists all green).
