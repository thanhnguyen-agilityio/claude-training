## Skills today

### Developer track

**Playwright MCP (devs too)** — Drive and verify the running app from a session.
*How to set up:* See [Day 8](day-08.md) for the setup steps.

**Role extras: Claude in Chrome (web), iOS Simulator pane loop (mobile), computer use (game/editor)** — Verify the actual product, not just the code.
*How to set up:*
- **Claude in Chrome (web):** install the *Claude in Chrome* extension from the Chrome Web Store (Chrome/Edge, v1.0.36+). When Claude first needs the browser, accept the "Claude wants to use your browser" prompt — or run `/chrome` to connect. Needs a direct Pro, Max, Team, or Enterprise plan.
- **iOS Simulator (mobile):** macOS + Desktop app only — the iOS Simulator pane opens automatically in the Code tab when needed.
- **Computer use (game/editor):** in a Code session run `/mcp` and enable the computer-use option (macOS).
