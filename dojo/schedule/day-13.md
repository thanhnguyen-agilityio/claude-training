# Day 13 — Build

Everyone

- Devs implement in parallel isolated sessions, plan mode first, PRs per ticket.
- QA authors the automated suite alongside; BA updates the spec as questions resolve.
- **Rule of the day:** every artifact of work (spec, tests, PRs, notes) is Claude-assisted and human-edited.

## Skills today

**Plan mode** — Approve the plan before any code is written — the biggest lever for trusting agentic work on real tickets.
*How to set up:* See [Day 4](day-04.md) for the setup steps.

**Git worktrees + parallel sessions** — Two tickets in flight, two isolated agents, zero crosstalk.
*How to set up:* See [Day 6](day-06.md) for the setup steps.
