# Course Catalog

Claude Academy · Coursera · Official docs

Recommended courses, all verified live as of 2026-10-07.

Primary source is **Claude Academy** — Anthropic's official course site at [academy.claude.com](https://academy.claude.com/) (reachable from claude.ai; formerly branded Anthropic Academy). Courses are free with a claude.ai sign-in and self-paced. The Claude Code product also ships **interactive in-product lessons**, and the official docs are the canonical reference — both count as coursework in this plan.

"Day" references point into the [day-by-day schedule](schedule.md).

## Selection rules used here

- Only courses that exist on the official sites today; no third-party "Claude masterclasses".
- Every course is mapped to a schedule day so it's homework, not homework theater.
- Optional courses (API, MCP advanced, human-agent teams) are for the people whose next step they genuinely are — the plan doesn't require them.
