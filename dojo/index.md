AI Tools - Training

# Plan

A full-time, day-by-day training program that makes Claude the core working tool for a software consulting & development company: web, game, and mobile developers plus BA/QA.

**Centerpiece:** the Claude Desktop app (Chat, Cowork, and Code tabs), with [Claude Code](https://code.claude.com/docs) in the **Code** tab as the developer's main environment and Claude/Cowork as the BA/QA environment.

[Open the 15-day schedule](schedule.md) · [Start Day 1](schedule/day-01.md) · [Shared fundamentals](fundamentals.md)

All feature and course names in this plan were verified against the official documentation (code.claude.com, academy.claude.com, coursera.org) on **2026-10-07**. Names change fast — re-check the linked doc pages before each week.

## How the plan is organized

| Page | What it covers | Audience |
| --- | --- | --- |
| [Shared fundamentals](fundamentals.md) | Fundamental skills for **everyone**: analyze a ticket, reproduce/understand, fix/develop, submit a PR, review & merge — plus the git and Claude tooling habits behind it | All staff |
| [Developer track](developer.md) | Claude Code Desktop deep dive: sessions, panes, memory, skills, MCP, hooks, parallel agents, and the four named features (artifacts, loop, remote control, ultracode) | Web / game / mobile devs |
| [BA/QA track](ba-qa.md) | Claude Desktop for BA (ticket planning) and QA (test planning + automated testing) | BA / QA |
| [Course catalog](courses.md) | Recommended courses from Claude Academy (claude.ai's course site), Coursera, and official docs, mapped to tracks and days | All |
| [Day-by-day schedule](schedule.md) | 15 full-time working days: Days 1–3 shared fundamentals, Days 4–11 split tracks, Days 12–15 cross-functional capstone | All |
